# How To Create Beautiful Animations Using Remotion With Claude Code

After watching, you can spin up broadcast-quality animated graphics for your own videos — lower-thirds, animated benchmark charts, code-typing intros — by describing them to Claude Code and rendering them with Remotion, no After Effects and no motion-design skills required.



https://youtu.be/rXAl6_byG80

## Animation Prompts Used Within The Video

Here are the prompts used within the examples presented in the video - feel free to copy + paste to recreate them for your own use.

### Example 1 @4:25 </br>
```In this Remotion project, create a composition that shows a name-and-role lower-third that slides in from the left with a spring, holds about four seconds, then slides out. Make the name, role, and accent colour props. Put a thin glowing accent bar to the left of the text, and export it transparent so it drops straight over my face-cam. ```

</br></br>

### Example 2 @4:30 </br>
```Build a full-frame title card with a dark radial-gradient background. Take the title string split it into words, and have each word spring up into place one after another in a stagger, alternating between white and my accent orange. A subtitle fades up underneath once the title lands. Title and subtitle are props.```

</br></br>

### Example 3 @4:33 </br>
```Build a horizontal bar chart comparing a Raspberry Pi 5 and a mini PC across CPU, RAM, idle power and price. Two bars per metric, one per device, normalised so the bigger value fills the row. Bars grow in with a spring, the numbers count up next to them, and a legend shows which colour is which device. Read all the data and labels from a benchmarks.json file so I can change four numbers and re-render. Dark gradient background.```

</br></br>

### Example 4 @4:36 </br>
```Build a small dashboard metric card: a label, a big value that counts up, a coloured up/down delta percentage, and a sparkline along the bottom that draws itself in left-to-right. The card scales in with a spring. Label, value, delta percent, points array and colour are props.```

</br></br>

### Example 5 @4:40 </br>
```Type out this terminal command character-by-character with a blinking cursor and syntax highlighting (command name in green, flags in yellow, anything with a slash or version in cyan), then run it and print the output lines one at a time underneath. Put it in a macOS terminal window with the traffic-light buttons. Command and output lines are props.```

</br></br>

### Example 6 @4:47 </br>
```Make a "now playing" music card: album art on the left with a dancing equalizer, and on the right a "Now Playing" label, the track title and artist, a progress bar that advances, and the elapsed and total time. Title, artist and accent colour are props. Transparent.```
